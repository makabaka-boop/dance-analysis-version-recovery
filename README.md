# 舞台轨迹检查 · Stage Trajectory Check

空仓库起步的 Vue 3 + TypeScript 舞台轨迹冲突检查页。舞者沿排练标记在不同时刻穿过同一位置，
逐帧截图会漏掉两帧之间的相撞——本工具对**每对舞者时间重叠的每对匀速线段精确求相对距离平方
的最小值**，全程整数 / BigInt 分数运算，不按帧采样，也不用 SVG 像素坐标做判定。

## 运行

```bash
npm install
npm run dev        # 本地开发 http://localhost:5173
npm test           # Vitest（40 个用例，含小样本枚举分段对拍）
npm run build      # vue-tsc 类型检查 + 生产构建到 dist/

# Compose 提供 stage 页面（多阶段：node 构建 → nginx 提供静态页）
docker compose up --build
# http://localhost:8080
```

## 问题模型

- 一次编排 2..8 名舞者；每人 2..25 个路点。
- 路点：整数时间 `t ∈ [0,600]` **严格递增**，整数坐标 `|x|,|y| ≤ 100`，另有非负整数安全半径。
- 相邻路点间**匀速直线**运动；位置是时间的有理函数。
- 冲突定义：两舞者的相对距离 **≤ 半径和**（含等号）。

## 精确几何（`src/core/`）

两线段在时间重叠区间 `[lo, hi]`（含端点；零长度的端点相接也检查）内：

```
位置（d = t1-t0，整数）：  X(t) = (x0·d + dx·(t-t0)) / d
相对位移分量（dA、dB 为两段时长）：
  RXnum(t) = rx·t + sx     分母 dA·dB
  RYnum(t) = ry·t + sy     分母 dA·dB
距离平方：
  d²(t) = (P·t² + Q·t + R) / (dA²·dB²)      （P,Q,R 均为整数）
```

- `P = 0`（相对静止）：最小值恒为 `R/(dA²·dB²)`，发生时刻取重叠起点。
- 否则抛物线顶点 `t* = -Q/(2P)`，用分数夹到 `[lo, hi]` 后回代求值。
- 冲突比较：`分子 ≤ (rA+rB)² · 分母`，BigInt 整数比较；半径和平方是整数。
- 系数运算中两个 ~10^13 量级整数之差可能超过 `Number.MAX_SAFE_INTEGER`，所以一律 `bigint`。

`Fraction`（`fraction.ts`）：BigInt 分子分母、构造约分、分母恒正；`toNumber/toFixedTrunc`
只用于滑块与 SVG 展示，**判定路径不出现浮点**。

## 页面

- **舞台俯视图**（`StageView.vue`）：全部轨迹与路点、当前时间位置、安全半径圆盘；选中冲突后
  高亮该对舞者，并在见证时刻用虚线连接两人位置。
- **时间滑块**（`TimeSlider.vue`）：0..600，刻度 1/100；每条冲突在其精确发生时刻画一个色点，
  点击直接跳到该分数时刻；支持 1× 播放。
- **冲突报告**（`ConflictReport.vue`）：逐对列出冲突线段（双方段下标与时间区间）、重叠区间、
  `min d²` 的精确分数与小数近似、`(r₁+r₂)²` 阈值，以及发生时刻 `t*` 的分数。
- **编辑器**（`DancerEditor.vue`）：增删舞者 / 路点、改半径与坐标，内置四个预设：擦边通过
  （`d²=4/17 @ t=8/17`）、反向相遇（`t=5` 精确相撞）、端点相接（零长度重叠）、三人多段
  （含 `d = 半径和` 的边界冲突）。校验失败时暂停分析并逐条列出原因。

## Web Worker 与版本号

分析在 `analysis.worker.ts` 中进行。每次编辑（60ms 防抖合并连续输入）`version++`，请求与
响应都携带该版本号；主线程收到响应时若版本已过期直接丢弃，从机制上保证旧编辑的迟到结果不会
覆盖新结果。Vitest/jsdom 等无 Worker 环境下自动回落到主线程同步计算，版本核对逻辑相同。

## 测试

- `fraction.test.ts`：约分、四则、比较、超 `2^53` 整数精度、JSON 往返。
- `geometry.test.ts`：擦边（段内分数顶点）、反向相遇、**端点相接（零长度重叠）**、时间不重叠、
  相对静止、跨分母（两段时长不同）、顶点越界取端点。
- `choreography.test.ts`：全部输入约束校验 + 编排级枚举，覆盖 ≤ 等号边界。
- `brute.test.ts`：**小样本枚举分段对拍**——种子随机生成 2..4 人、2..5 路点的小编排，用一套
  独立的浮点「解析抛物线 + 密集采样」oracle 与精确实现逐线段对核对：重叠区间、最小距离、发生
  时刻、冲突判定；另有一条警示用例演示 400 份采样会落在格点之间而漏掉精确相遇。
- `useCollisionAnalysis.test.ts`：版本号协议（旧版本迟到结果丢弃）。
- `App.test.ts`：页面挂载与默认场景渲染冒烟。
